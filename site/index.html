A FEW SMALL QUESTIONS

Can I undo a deletion?

No. Deleting a URL removes all of its visits. Review your selection before confirming. Chrome may sync history deletions across signed-in devices.

What permissions does it need?

history supports search and deletion. activeTab and scripting support user-invoked website entries and the in-page modal. contextMenus adds the right-click entry; storage saves kept websites and opening preferences on this device. No remotely hosted code.

Does it scan every record?

Each scan reads up to 100,000 distinct URLs by last visit. A notice appears if that limit is reached; older records may be outside the results.

Is it on the Chrome Web Store yet?

Yes. Install the current published version from the Chrome Web Store, or download the package below for developer mode.
