Privacy policy · Updated November 8, 2026

What the extension does

History Sweep has a single purpose: helping you search, select, and delete Chrome browsing history in batches.

What it processes

When you type a keyword for search suggestions or start a search, date filter, or current-website lookup, the extension reads page URLs, titles, last-visit times, and visit counts through Chrome’s history API. Search results and suggestion indexes stay in the extension page and its local Worker memory. Confirmed deletion uses a temporary in-memory background queue that continues when the window closes. Completed queue results are discarded within 60 seconds, or earlier when the worker stops. Interrupted manual deletions do not resume after Chrome exits or the extension reloads.

What is saved locally

The extension saves your language and appearance preferences in persistent local storage and your user-entered kept-domain rules and opening preference in chrome.storage.local on this device only, alongside verified daily cleanup counts and one summary per website/day: hostname, latest page title when available, and last-visit time. Complete deleted URLs are not saved. Earlier totals may lack website details. Browsing activity is read from retained history without saving a copy. Search conditions and date filters pass to the full page through a one-time memory handoff and are not included in its URL. This website stores only your language preference.

Since v0.5.0, the extension also saves your default browsing view, relative range and Private cleanup preference locally. Once Private cleanup is saved and enabled, new cleanups do not save counts or website details; existing activity remains.

Configuration sync and backup (since v0.5.0)

Configuration sync is available from v0.5.0 and absent from v0.4.0.

In extension settings, you can opt into WebDAV and manually transfer lightweight configuration: language, appearance, opening preference, and reserved tag and domain-category label settings. Browsing history, cleanup activity, kept-domain rules, browsing defaults and Private cleanup preferences are excluded, as are v0.6.0 cleanup tasks, nameplates, view order and soft privacy preferences. Connection credentials stay in the current Chrome profile and are used only to authenticate to your chosen server; they are not included in the remote configuration file. Transfers require optional access to the selected server and use HTTPS; the provider can read the remote JSON. Manually exported encrypted disk backups include connection credentials and lightweight configuration; backup passwords are not stored. Chrome removes extension storage on uninstall. Reinstallation recovery requires manually importing the backup file with its password.

Store update checks (since v0.5.0)

When the store-installed extension opens, it requests public version metadata from sweep.agentclub.dev outside a 15-minute cooldown. The request sends no cookies, referrer, search terms, browsing history or configuration and receives only a JSON version hint; the hosting provider still receives standard connection information such as an IP address. Only the last check time and installed version are saved locally. A newer-version hint triggers Chrome’s official update check; update packages come from the Chrome Web Store. An update button appears once Chrome confirms the download, and cannot reload the extension during deletion or verification. Unpacked installations do not make this check.

Local tasks and preferences in v0.6.0

Tasks you create save their domains, matching mode, inactivity threshold, schedule, pause state and next run locally. The alarms permission wakes these tasks. Each run reads current history, honors kept websites, deletes matching URLs and verifies the result. Browser shutdown or sleep may delay execution; overdue tasks rescan and catch up once on restart. Run summaries retain counts and website summaries, without persisting complete matched URLs. Private cleanup suppresses new completion activity; soft privacy hides cleanup activity without deleting existing records. View order, visibility and each nameplate's decorative number, finish and first-received date also stay local and are excluded from sync and backup. Uninstalling clears this local data.

Local tools and exports in the v0.7.0 candidate

The extension additionally saves explicitly configured searches, advanced conditions, exact kept URLs, link-cleaning parameter rules, manual website labels and optional label styles locally. Exact kept URLs are configuration and can remain after history is deleted. Label images are cropped locally into 320 × 128 WebP thumbnails without source filenames or metadata. Recommendation rules, cleanup-evidence thresholds and animation timestamps stay local; soft privacy hides cleanup-derived recommendations. Interrupted manual cleanup retains only an operation marker without URLs, titles or counts and never resumes deletion. Explicit activity clearing removes only activity totals and website summaries, not browsing history.

You can explicitly include kept domains/URLs, browsing defaults and task scopes in password-encrypted disk backups. Import previews replacement of the selected sections; restored tasks remain paused until previewed and enabled. This selectively extends the earlier backup exclusions above in v0.7.0, without changing WebDAV scope. Saved searches, labels and their images, browsing history, cleanup activity, nameplates, interruption markers and task execution results are excluded from these backup sections.

You can export selected results as URL text or CSV, potentially containing complete URLs, titles and last-visit times. Exported files are not encrypted and remain after history clearing or uninstall. Export and cleaned-link copying make no server request; any subsequent file sharing is your choice. Visit details and deletion impact read available local history without creating a recovery copy or undo capability.

Transfers and limited use

The extension sends no browsing history and contains no analytics, advertising, or remote scripts. We do not collect, sell, or share browsing records. Information accessed through Google APIs is used solely for these visible features, in accordance with the Chrome Web Store User Data Policy and its Limited Use restrictions.

The first time you trigger the robot dance, the extension downloads a WebP animation sprite sheet from the History Sweep website and caches it on your device for offline playback. The website host receives standard connection information such as your IP address.

Link cleanup and Agent access

Link cleanup rules, parameter names and path exceptions stay on this device. When you enable automatic cleanup and grant access to a site, the extension uses Chrome’s declarative network rules to clean outgoing links for that site. Chrome opens the resulting links normally.

Agent access uses Native Messaging to communicate with the companion you install. Your chosen agent can receive task domains, schedules and aggregate preview counts and may send them to its model provider. These tools omit complete page URLs, titles and visit times. Task changes and execution require approval in the extension. Installer and update providers receive standard connection information such as IP addresses.

Permissions and deletion

The history permission supports searching and deletion, activeTab supports user-invoked current website searches or the in-page modal, scripting inserts the chosen modal host, contextMenus adds the website right-click entry, and storage saves local rules and preferences, favicon displays Chrome-provided website icons, and v0.6.0 uses alarms for the cleanup schedules you enable. The extension does not read website passwords, cookies, bookmarks, or page content. Website entries only start searches, without automatic selection or deletion. Date filters match a URL's last visit; confirmed deletion removes all visits to each selected URL, including visits outside the date range, and cannot be undone. Chrome’s own synchronization settings may propagate deletions to other signed-in devices.

This website

This site adds no analytics, advertising, or third-party fonts. Product screenshots use illustrative data. Tool comparisons may load attributed official images from third-party image hosts, which receive standard connection information. The site is hosted on Cloudflare. Cloudflare may process standard request information such as IP addresses to deliver, secure, and operate the site; see the Cloudflare Privacy Policy for details.

Contact and release status

The website is publicly available at sweep.agentclub.dev. The Chrome extension is publicly listed on the Chrome Web Store. For support or privacy questions, contact us through GitHub Issues.
