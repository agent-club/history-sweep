What the extension does

History Sweep has a single purpose: helping you search, select, and delete Chrome browsing history in batches.

What it processes

When you type a keyword for search suggestions or start a search, date filter, or current-website lookup, the extension reads page URLs, titles, last-visit times, and visit counts through Chrome’s history API. Search results and suggestion indexes stay in the extension page and its local Worker memory. Confirmed deletion uses a temporary in-memory background queue that continues when the window closes. Completed queue results are discarded within 60 seconds, or earlier when the worker stops. Tasks do not resume after Chrome exits or the extension reloads.

What is saved locally

The extension saves your language and appearance preferences in persistent local storage and your user-entered kept-domain rules and opening preference in chrome.storage.local on this device only, alongside verified daily cleanup counts and one summary per website/day: hostname, latest page title when available, and last-visit time. Complete deleted URLs are not saved. Earlier totals may lack website details. Browsing activity is read from retained history without saving a copy. Search conditions and date filters pass to the full page through a one-time memory handoff and are not included in its URL. This website stores only your language preference.

The v0.5.0 candidate also saves your default browsing view, relative range and Private cleanup preference locally. Once Private cleanup is saved and enabled, new cleanups do not save counts or website details; existing activity remains.

Configuration sync and backup in the v0.5.0 candidate

Configuration sync is included in the v0.5.0 candidate and absent from v0.4.0. This description does not announce public availability of the new release.

In extension settings, you can opt into WebDAV and manually transfer lightweight configuration: language, appearance, opening preference, and reserved tag and domain-category label settings. Browsing history, cleanup activity, kept-domain rules, browsing defaults and Private cleanup preferences are excluded. Connection credentials stay in the current Chrome profile and are used only to authenticate to your chosen server; they are not included in the remote configuration file. Transfers require optional access to the selected server and use HTTPS; the provider can read the remote JSON. Manually exported encrypted disk backups include connection credentials and lightweight configuration; backup passwords are not stored. Chrome removes extension storage on uninstall. Reinstallation recovery requires manually importing the backup file with its password.

Store update checks in the v0.5.0 candidate

When the store-installed extension opens, it requests public version metadata from sweep.agentclub.dev outside a 15-minute cooldown. The request sends no cookies, referrer, search terms, browsing history or configuration and receives only a JSON version hint; the hosting provider still receives standard connection information such as an IP address. Only the last check time and installed version are saved locally. A newer-version hint triggers Chrome’s official update check; update packages come from the Chrome Web Store. An update button appears once Chrome confirms the download, and cannot reload the extension during deletion or verification. Unpacked installations do not make this check.

Transfers and limited use

The extension sends no browsing history and contains no analytics, advertising, or remote scripts. We do not collect, sell, or share browsing records. Information accessed through Google APIs is used solely for these visible features, in accordance with the Chrome Web Store User Data Policy and its Limited Use restrictions.

Permissions and deletion

The history permission supports searching and deletion, activeTab supports user-invoked current website searches or the in-page modal, scripting inserts the chosen modal host, contextMenus adds the website right-click entry, and storage saves local kept-domain rules and the opening preference. The extension does not read website passwords, cookies, bookmarks, or page content. Website entries only start searches, without automatic selection or deletion. Date filters match a URL's last visit; confirmed deletion removes all visits to each selected URL, including visits outside the date range, and cannot be undone. Chrome’s own synchronization settings may propagate deletions to other signed-in devices.

This website

This site adds no analytics, advertising, or third-party fonts. Product screenshots use illustrative data. Tool comparisons may load attributed official images from third-party image hosts, which receive standard connection information. The site is hosted on Cloudflare. Cloudflare may process standard request information such as IP addresses to deliver, secure, and operate the site; see the Cloudflare Privacy Policy for details.

Contact and release status

The website is publicly available at sweep.agentclub.dev. The Chrome extension is publicly listed on the Chrome Web Store. For support or privacy questions, contact us through GitHub Issues.
