# History Sweep

本文用于 v0.6.0 更新准备，不代表商店已提供新版。

## 简短描述
精准搜索、一键全选、批量清理浏览历史。所有操作都在本机完成。

## 详细介绍
五百条历史记录，不必点五百次。

History Sweep 帮你找到需要清理的浏览历史，一次选中所有匹配 URL，再确认批量删除。

精准找到目标
支持智能匹配、精确域名、域名及子域名、标题或 URL 关键词搜索。输入 X 匹配完整域名标签 x，包括 x.com。多个站点用逗号分隔。

一键全选，保留例外
全选覆盖全部匹配项，不只当前预览。你也可以取消勾选需要保留的页面。删除前会显示数量并要求确认。

按期间频次浏览
选择“按频次”，按所选期间的访问次数降序查看页面，同次数按期间最后访问排序。期间访问过、之后又访问过的页面仍可包含。读取不完整时报错，不展示部分排名；删除仍移除选中网址的全部访问。

小窗、浮窗与完整页面
没有保存打开偏好时，默认在当前网页上打开浮窗，已有选择保留。工具栏小窗适合快速清理；完整页面会带入当前搜索条件和日期筛选，也可在打开方式设置中选择页面内浮窗。通过当前网站按钮或网页右键菜单发起精确域名搜索，不会自动选择或删除。偏好设置显示 Chrome 当前快捷键并可打开修改入口，快捷键在 Chrome 获得焦点时生效。长列表可通过“返回顶部”快速回到开头。

按日期筛选，保留重要网站
按最后访问时间选择预设范围或包含起止当天的自定义日期。保存保留网站规则，将域名及其子域名排除在选择范围外。首次默认按网站浏览近一个星期，覆盖今天及之前六个本地自然日，不自动选中。可在偏好设置中保存默认视图和相对时间；临时筛选不改变默认值，自定义日期仅临时使用。关键词搜索仍默认全部时间，除非明确选择范围。日期和网站视图按网址的最后访问时间统计不同网页。删除预览中可逐项核对页面。

本机搜索建议
输入关键词时，利用本机浏览历史补全域名、查找标题或 URL。搜索建议及索引只在本机内存中处理，不使用远程服务。

本地活动与无痕清理
查看本地浏览和清理活动，优先展示浏览记录，点击“展开分析／收起分析”控制面板。保存并开启“无痕清理”后，新清理不记录次数或网站明细，已有本地活动保留。

本机定时清理
按精确域名或域名及子域名创建任务，选择单次、每天、每周或每月执行，可附加完整天数未访问条件。启用前先预览，保存不会立即删除。保留网站优先，可暂停单条或全部任务。Chrome 必须运行；休眠或关闭可能延迟执行，重启后到期任务重新扫描并补跑一次，再继续计划。任务及执行摘要仅留在本机，不参与同步或备份。

按习惯使用
调整视图顺序及展示、复制结果完整 URL，或隐藏清理活动而保留记录。在插件内关闭未保存的偏好设置时会先询问。装饰铭牌仅保存在本机，不关联账号或金钱权益。偏好设置提供快速上手和离线版本说明。

手动配置同步与加密备份
在“偏好设置 → 同步与磁盘备份”中保存 HTTPS WebDAV 文件地址，手动传输语言、外观和打开方式。不传输浏览历史、清理活动、保留网站、默认浏览设置或无痕清理偏好；主动测试或传输时才请求所选主机权限。远端 JSON 可由服务商读取。密码加密备份须手动导出到插件目录之外，卸载后通过文件和密码恢复；Chrome 卸载插件会清除插件存储。备份是手动快照，不是自动同步。

隐私优先
浏览记录仅在浏览器内处理，不由插件上传。无需账号，无广告，无统计追踪。history 权限用于搜索和删除历史，activeTab 用于用户主动发起的当前网站搜索和页面内 Modal，scripting 插入用户选择的 Modal 容器，contextMenus 提供网站右键入口，storage 将保留域名规则、打开方式偏好和每日清理次数及网站域名、最近标题、最后访问时间摘要仅保存在本机，不保存已删完整 URL；alarms 用于调度你主动启用的清理任务；favicon 在网站分组和本地活动中显示 Chrome 提供的网站图标。不读取网站密码、Cookie、书签或网页内容。你主动输入的 WebDAV 连接凭据保存在本机，只用于向所选服务器认证；备份文件对其加密。可选 HTTPS 主机权限用于你主动发起的 WebDAV 操作。

官方商店安装版打开时，最多每 15 分钟请求一次公开版本提示，适用时再由 Chrome 检查更新。不发送浏览历史、搜索词或配置，托管方仍接收标准连接信息。只有 Chrome 确认下载完成才启用更新按钮；删除和复查期间不能重新加载。解压安装版跳过此请求，不执行远程脚本。

英文和简体中文
首次打开默认英文，可随时切换到简体中文。语言偏好仅保存在本机。

使用说明
删除 URL 会移除其全部访问记录，包括日期筛选范围之外的访问，且无法撤销。Chrome 可能将删除同步至其他已登录设备。确认后的删除在关闭插件窗口后仍会继续。请保持 Chrome 运行；重新打开并搜索可查看结果。退出 Chrome 后中断的手动删除无法恢复；定时任务在 Chrome 再次运行时重新扫描。每次扫描最多读取 100,000 个不同 URL；达到上限时会提示。删除后会复查，并指出仍然存在的选中项。
