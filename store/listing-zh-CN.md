# History Sweep

## 简短描述
精准搜索、一键全选、批量清理浏览历史。所有操作都在本机完成。

## 详细介绍
五百条历史记录，不必点五百次。

History Sweep 帮你找到需要清理的浏览历史，一次选中所有匹配 URL，再确认批量删除。

精准找到目标
支持智能匹配、精确域名、域名及子域名、标题或 URL 关键词搜索。输入 X 匹配完整域名标签 x，包括 x.com。多个站点用逗号分隔。

一键全选，保留例外
全选覆盖全部匹配项，不只当前预览。你也可以取消勾选需要保留的页面。删除前会显示数量并要求确认。

小窗与完整页面
工具栏小窗适合快速清理；完整页面会带入当前搜索条件和日期筛选，也可在打开方式设置中选择页面内浮窗。通过当前网站按钮或网页右键菜单发起精确域名搜索，不会自动选择或删除。

按日期筛选，保留重要网站
按最后访问时间选择预设范围或包含起止当天的自定义日期。保存保留网站规则，将域名及其子域名排除在选择范围外。按网站查看结果，并在删除预览中逐项核对页面。

本机搜索建议
输入关键词时，利用本机浏览历史补全域名、查找标题或 URL。搜索建议及索引只在本机内存中处理，不使用远程服务。

隐私优先
浏览记录仅在浏览器内处理，不由插件上传。无需账号，无广告，无统计追踪。history 权限用于搜索和删除历史，activeTab 用于用户主动发起的当前网站搜索和页面内 Modal，scripting 插入用户选择的 Modal 容器，contextMenus 提供网站右键入口，storage 将保留域名规则和打开方式偏好仅保存在本机。不读取密码、Cookie、书签或网页内容。

英文和简体中文
首次打开默认英文，可随时切换到简体中文。语言偏好仅保存在本机。

使用说明
删除 URL 会移除其全部访问记录，包括日期筛选范围之外的访问，且无法撤销。Chrome 可能将删除同步至其他已登录设备。确认后的删除在关闭插件窗口后仍会继续。请保持 Chrome 运行；重新打开并搜索可查看结果。退出 Chrome 后任务无法恢复。每次扫描最多读取 100,000 个不同 URL；达到上限时会提示。删除后会复查，并指出仍然存在的选中项。
