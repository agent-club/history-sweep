## Scope

- Local cleanup tasks with exact-domain or subdomain matching, optional inactivity conditions, one-time/daily/weekly/monthly schedules, previews and pause controls. Kept websites take priority. Saving alone does not delete. Browser shutdown or sleep may delay runs; overdue tasks rescan once after restart.
- A shared settings window for cleanup tasks and WebDAV, view order and visibility, and unsaved-preference confirmation.
- Full URL copying, explicit activity expansion, Soft privacy, local nameplates, Quick start and offline bilingual release notes.
- Update details distinguish published versions from downloads confirmed by Chrome.

Website classification, history tags and tracking-parameter removal remain outside this release. Interrupted manual deletions do not resume; scheduled tasks rescan after restart. Deleting a URL removes all its visits and cannot be undone.

## Permissions and data practices

Single purpose: Find, review and delete Chrome browsing history, manually or through local schedules the user enables, with local preferences and user-initiated configuration backup.

The existing history, activeTab, scripting, contextMenus, storage and favicon permissions retain their documented purpose. Storage also holds local task schedules, pause state, next runs, view preferences and decorative nameplates. Complete deleted URLs are not retained as activity records.

**New alarms justification:** Wake cleanup schedules explicitly enabled by the user. Each run rescans current local history, applies kept-site protection and verifies deletion. No server scheduler or automatic task creation is involved.

Optional HTTPS host access supports manual WebDAV operations to the selected host. Configuration transfer excludes browsing history, cleanup activity, kept sites, browsing defaults, privacy preferences, cleanup tasks, view order and nameplates. See the bilingual privacy source for provider authentication, encrypted disk backup and uninstall recovery disclosures. No operational authentication values are included in these materials.

Private cleanup suppresses new completion activity. Soft privacy hides existing activity without deleting it. Uninstall removes extension storage. Public update requests contain no history, search or settings; the host receives standard connection information. Store updates remain Chrome-managed. There is no analytics, advertising or remote executable code.

Review current dashboard permission justifications and data-use disclosures before submission. Local history access and optional provider authentication require accurate disclosure; absence of history uploads alone does not determine dashboard fields. Live dashboard values have not been inspected here.

## Reviewer steps

1. Use a disposable profile and synthetic visits. Switch browsing views while retaining selection, then save defaults and reopen.
2. Copy a full URL without changing selection. Explicitly expand and collapse activity.
3. Change settings and close. Check keep editing, discard and save outcomes; reorder or hide views while retaining at least one visible view.
4. Create a task for a synthetic domain. Preview, save paused and enable only after reviewing its scope. Check kept-site exclusions, next run and individual/global pause controls.
5. Delete only disposable URLs. Check that unselected and kept URLs remain. Manual deletion requires confirmation; enabled schedules execute their saved scope automatically.
6. Check Private cleanup recording and Soft privacy display separately. Open Quick start and offline notes in both languages; v0.6.0 is Published and v0.5.0 remains available.
7. Open the local nameplate and check reduced motion. Open inline sync and test backup using disposable inputs. WebDAV requires the reviewer's own controlled endpoint.
