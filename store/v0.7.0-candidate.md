## Included scope

- Recommended cleanup with explicit website rules, per-URL inactivity conditions, recent local cleanup evidence, protocol choices and inline reasons. Reviewing recommendations never selects or deletes; kept websites and exact URLs take priority. Soft privacy suppresses cleanup-derived evidence.
- Saved searches and explicit AND conditions; exact-URL protection enforced by manual and scheduled cleanup; visit details and deletion-impact inspection.
- Manual exact-host labels with per-label colors, built-in textures or locally processed images. This does not introduce automatic website classification or record-level tags.
- Previewed cleaned-link copying and selected-result URL/CSV export. Exports are unencrypted files and remain after uninstall. No automatic navigation or request rewriting.
- Explicit Local activity clearing and a minimal interruption marker without target URLs, titles or counts. Interrupted manual cleanup never resumes automatically.
- Optional encrypted disk sections for protection, browsing defaults and task scopes. Restore previews replacement and keeps imported tasks paused. WebDAV scope is unchanged.
- Progressive result rendering, settings tabs with retained drafts, task actions with preview/confirmation, and the current date-picker refinements. Release verification also fixed the search-help panel extending beyond a 320px viewport.

Deleting a URL still removes all visits, including visits outside the filter period, and cannot be undone. Chrome must run for scheduled tasks; shutdown/sleep can delay execution.

## Privacy and dashboard copy

Single purpose: Help users find, review, protect and delete Chrome browsing history, manually or through local schedules they enable, with local settings and user-initiated export or configuration backup.

No new permissions: history, activeTab, scripting, contextMenus, storage, favicon and alarms, plus optional HTTPS access for manual WebDAV operations. The history permission also reads available visits for details/impact; storage additionally saves explicit searches, exact kept URLs, local labels/styles, link-cleaning rules, recommendations and the minimal interruption marker.

WebDAV continues to transfer only its allowlisted lightweight configuration. It excludes history, activity, exact URL protection, saved searches, local labels/images, recommendations and the new backup sections. Encrypted disk recovery can explicitly include protection, browsing defaults and paused task scopes; history, activity and labels/images are excluded. User-triggered selected-result exports can contain full URLs, titles and timestamps and are not encrypted.

The revised bilingual [privacy source](../site/privacy.html) is deployed at [the privacy page](https://sweep.agentclub.dev/privacy). The live policy and relevant dashboard fields were verified during the execution recorded below. No real authentication values or browsing data are included in this pack.
